ZXMAK2: управление и перенос

Тестовая портативная сборка v91. Она станет основной только после подтверждения пользователя. Добавлена ZXM-SoundCard Extreme Rev.03 в ZXBUS ZX Evolution. Логика SD-папок и прежних карт сохранена.

Общие клавиши главного окна

Это команды оболочки ZXMAK2, а не сочетания внутри NedoOS, TR-DOS, игры или плеера. Открытое меню и диалоги получают клавиши сами: Escape, Enter и стрелки не должны одновременно уходить машине. При потере фокуса удерживаемые клавиши освобождаются.

Различия между машинами

Общие команды оболочки остаются общими. Доступность CMOS, NMI, IDE, SD, Quick Load и конкретных карт определяется выбранной конфигурацией. Смена машины загружает её шаблон; это не система независимых пользовательских профилей для каждой модели.

Носители и сохранение

Можно подключать внутренние и внешние файлы. Внутренние пути записываются относительно папки EXE. При переносе отсутствующий ранее подключённый носитель означает пустой слот, без создания подменного образа.

Выбранная SD-папка доступна для записи. Save сохраняет только изменения машины в эту же папку. Полной копии нет, путь не переключается. PC-правки делайте в той же папке; Refresh перечитывает её. Отдельно подключённый внешний SD-образ сохраняется самостоятельным RAW IMG в Data/Saves/SD-Images. Внешняя дискета сохраняется локальной копией в Data/Saves/Floppy.

Окно Saving SD folder показывает стадию сохранения. Временные данные относятся только к изменённым файлам, не ко всей коллекции. Машина остаётся на паузе; дождитесь завершения, не закрывайте процесс принудительно.

Если прежние настройки v87–v89 уже указывают на старую сохранённую копию, выберите вашу исходную папку через Mount folder as SD. Старые копии автоматически не удаляются и пути не угадываются.

Для внешнего HDD первая фактическая запись создаёт полный локальный образ в Data/Saves/HDD. Копирование большого HDD может занять время и требует свободного места; при подключении копирование не выполняется.

Refresh Folder

  • Только PC-изменения: папка перечитывается без вопроса.
  • Есть изменения файлов в машине: Refresh (Save changes), Refresh (Without saving), Cancel.
  • Сохранение сначала применяет изменения сессии, затем перечитывает папку. Независимые PC-изменения должны сохраняться.
  • Один файл изменён с двух сторон: операция не должна молча выбирать победителя. Сохранение останавливается с объяснением; сессия остаётся доступной.
  • Успешный Refresh выполняет штатный холодный запуск, как смена SD-образа. Cancel и ошибка не выполняют этот запуск.

При закрытии по крестику, через File → Exit, извлечении и смене SD предлагается сохранить, отбросить изменения или отменить операцию. Обе SD-карты должны учитываться отдельно. Неудачное сохранение не считается успешным закрытием.

После аварии SD-папка запускается с текущим содержимым источника, без восстановления старого секторного журнала. Несохранённые изменения папки при аварии могут быть потеряны. Для обычных SD-образов сохранено отдельное восстановление сессии при совпадении источника, с подтверждением пользователя. Журналы внутренних образов имеют относительную идентичность. При обычном закрытии пользуйтесь сохранением.

Save SD session as image работает и без изменений. Результаты сохраняйте внутри папки эмулятора, но не внутри самой папки, которая сейчас подключена как SD.

Структура и перенос

  • Корень: EXE, файлы запуска, boot.zip, ROMS.PAK, ZXMAK2.vmz/.vmide/.cmos/.nvram.
  • Lib/Managed и Lib/Native: библиотеки. Не удаляйте DLL только потому, что их назначение неочевидно.
  • Config: настройки интерфейса, шаблоны машин, клавиатура, плагины и профили джойстиков.
  • Resources/ROMs: отдельные ROM; Resources/SoundBanks: звуковые банки.
  • Docs: справка и лицензии. Data: состояние, сессии, сохранения, журналы, кэш и временные файлы.

Для переноса закройте эмулятор с сохранением, затем скопируйте всю папку. Можно переименовать её и сменить диск. Не копируйте только EXE. Внутренние носители переедут вместе с папкой; внешние файлы — нет. Состояние прошивки MoonSound также переносится внутри Data.

Отсутствующий физический джойстик не должен подменяться случайным другим устройством. Клавиатурные назначения сохраняются. Размер окна адаптируется к рабочей области монитора; видеорежим гостевой машины этим не меняется.

Папка должна быть доступна для записи. Сборка не переключается скрытно на AppData или системный TEMP. Одна копия эмулятора не должна одновременно использоваться двумя процессами. Независимые копии могут работать отдельно.

Нужны Windows и совместимый .NET Framework (для длинных путей — 4.6.2 или новее, рекомендуется 4.8); некоторые графические режимы требуют legacy DirectX, нативные библиотеки — x86 runtime-зависимости. Переносимость не означает работу без системных компонентов на любом компьютере. Windows, драйверы и браузер справки могут оставлять собственные системные записи.

Что сбрасывается

F12 не удаляет файлы. Ctrl+F12 сбрасывает CMOS поддерживающей его текущей машины. Ctrl+Alt+F12 удаляет четыре активных файла состояния в корне после подтверждения и обработки изменений SD, затем перезапускает ZXMAK2. Он не удаляет всю Config/Data, музыку, пользовательские образы, ROMS.PAK, звуковые банки и виртуальную прошивку MoonSound.

Звук и прошивки

Звуковые карты внутри машины и устройство вывода Windows — разные вещи. Перенос не должен менять состав звуковых карт. Принятый общий звуковой тракт сохранён; тяжёлый эксперимент v83 в эту сборку не включён.

Отдельный Yamaha ROM в Resources/ROMs имеет приоритет перед ROMS.PAK. Старые расположения в корне и roms читаются для совместимости. Неправильный размер ROM — ошибка, а не повод незаметно выбрать другой файл. Изменяемая виртуальная flash хранится в Data/State/MoonSound и привязана к содержимому заводского ROM.

ZXM-SoundCard Extreme Rev.03

Alt+P → Other / ZXBUS PentEvo → активный слот → ZXM Extreme Rev.03 → Apply. Это отдельная плата MickLab: два YM2203, SAA1099 и четырёхканальный DAC TLC7226 (SounDrive). GS, MIDI UART, OPL3/OPL4 и Yamaha ROM в ней нет. Не выбирайте MultiSound/Max/OmniSound во втором слоте: порты пересекаются.

  • JP2: PentEvo mode — включён по умолчанию. Доступ SAA/DAC определяется защёлкой последнего чтения памяти. Без JP2 используется физический сигнал /DOS шины, а не просто флаг DOSEN.
  • JP1: Disable YM ports — выключен. При включении освобождает порты YM для внутренней музыки; управление самой Extreme через #FFFD/#FFFC продолжает работать. Если используете внутреннюю TSFM, её расширение MultiSound SAA ports должно быть выключено.
  • Legacy SAA ports — выключен (JP3 замкнут): адрес #05FF, данные #04FF. Включите для старых программ с #01FF/#00FF. Это аппаратная перемычка, не перенаправление AY-портов на SAA.
  • Частота YM задаётся программой через #FFFC: 3,5 / 2 / 4 МГц. Турборежим CPU не меняет высоту звука. Бит 7 #FFFC принудительно выбирает первый YM, не обнуляя второй.
  • Громкость платы регулируется под перемычками. Положение сохраняется в VMZ.

Rev.03 отличается от Rev.02 креплением, а не цифровой логикой. Использованы схема Rev.02 и CPLD Rev.01 V0100. Отдельный файл прошивки для запуска этой эмуляции не нужен. Сброс останавливает SAA clock, но не стирает регистры SAA/DAC: у этих чипов нет линии RESET.

Отладчик — отдельный контекст

В стандартном отладчике: F5 — остановка, F7 — шаг с заходом, F8 — шаг с обходом, F9 — продолжить. В Adlers F10 — продолжить, F12 — Stack/Breakpoints, Ctrl+F — поиск, Ctrl+G — переход в дизассемблере, Ctrl+D — переход в дампе, Escape — закрытие сообщения или окна. Это не назначения главного окна.

В ассемблере Ctrl+S сохраняет исходник, а не включает Maximum Speed. Сохраняйте исходники и результаты внутри комплекта. Если библиотека необязательной функции отсутствует, добавьте подходящую библиотеку вручную в Lib; не заменяйте её случайной DLL.

Сохранена историческая подробная документация: отладчик, ассемблер, команды. Её старые назначения клавиш и пути могут быть устаревшими: для них используйте разделы новой справки выше.
