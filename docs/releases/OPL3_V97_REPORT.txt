РЕАЛИЗАЦИЯ
Название в обоих слотах ZXBUS: ZX OPL3 (UR4QBP).
Источник: пользовательский ZX_OPL3.zip, схема ZX OPL3 Sound Card V1.0,
Alexander Karnaukh / UR4QBP, обновление схемы 2026-03-18.
SHA256 архива: 988FFC82DC6FDD98C245F926153FB935C78356A055011F0BBB6A4C0BE9441180.
Схема DD2/DD3: (port & 0x00FC)==0x00C4, обычный I/O, /M1=1.
Высокий байт адреса не участвует; DOS/ENDOS не подключён к дешифратору.
YMF262-M, 14.31818 MHz, отдельный ymfm::ymf262, native sample clock /288.
DOAB подключён к YAC512, DOCD не подключён: используются только выходы A/B.
/IRQ платы не подключён к ZXBUS; флаги таймеров читаются через статус.
Нет прошивки, ROM/RAM, PCM, MIDI UART или выдуманных перемычек.
Таймеры синхронизированы с 28-МГц master Tact PentEvo, независимо от mute
и host sample rate. Аудио — собственный лёгкий причинный linear resampler.
Никакие старые звуковые ядра и общий микшер не заменены.

Обычный MultiSound Rev.A2 разрешён в любом порядке слотов.
MoonSound, MultiSound Max и OmniSound отклоняются из-за #C4–#C7, до изменения
шины. Некорректный вручную отредактированный профиль также не принимается.
Подключение/удаление карты использует прежний cold hardware apply;
изменение только громкости — прежний live-volume путь без сброса.

   Все 65536 адресов чтения и записи сверены с маской; /M1/INTACK отдельно;
   верхние алиасы, DOSEN=0/1, handled, reset/reconnect, XML, оба слота.
   Статус #C4: 00 после сброса, C0 после Timer1, A0 после Timer2.
   Timer1=1152 input clocks, Timer2=4608 при значениях FF; точные границы,
   повтор, остановка/маска, очистка, работа при выключенном звуке.
   Z80-детектор настоящими IN/OUT: 00→C0 при 3,5/7/14 МГц.
   OPL2, все 18 OPL3 каналов, оба банка, A/B панорама, отключённые C/D,
   базовые 4-op и rhythm, сброс голосов, детерминированность разбиения.

ПАКЕТ И ВОСПРОИЗВОДИМОСТЬ
Full: готовая карта отдельно, без подключённых пользовательских носителей.
Clean: те же рабочие зависимости, без четырёх активных файлов состояния.
source: основной проект вместе с pinned OmniSound и обе Git history bundle.
rollback: нетронутый Full v96; checkpoints: исходный архив платы/старые WIP.
Build: MSBuild 2022 Release Any CPU; launcher остаётся x86 из v96.
Новая DLL: Zig 0.15.2, x86-windows-gnu, -O2, без fast-math.
SHA256 DLL: 3E1C9374DEE70910D289E7BB0B6204A767158B41197E824597BD2C983D5F5B07.
Импорты DLL: Kernel32 и Windows Universal CRT API sets. В Windows 10/11
UCRT системный; старые Windows этой сборкой не сертифицировались.
Лицензии ymfm и статических частей toolchain включены.
В build log только прежние предупреждения об отсутствующих ruleset-файлах.
Подготовка: tools/SoundCards/PrepareOpl3Runtime.ps1; проверки: RunOpl3.ps1,
RunOpl3Guest.ps1; исходный RealNedoProbe использован без изменения.
Воспроизведение гостевых проверок требует свою копию NedoOS/плеера/музыки;
пользовательские SD-папки, плеер и музыкальные файлы в release не добавлялись.

ОГРАНИЧЕНИЯ / НЕ ПРОВЕРЕНО
Не утверждаем электрическую/аналоговую идентичность: допуски генератора,
аналоговые ОУ/фильтры, шум, power-on bus transients не моделируются.
Режимы чтения вне документированного status offset 0 возвращают FF как
в выбранном ymfm; это не обещание для неопределённых состояний реального чипа.
Слишком быстрые нарушения минимального write spacing не отбрасываются.
Сохранён существующий 50 FPS host audio cadence; общая физическая калибровка
растра/аудио не входила в задачу. Старые машины и общий тракт не переделаны.
Сравнения с физической UR4QBP-платой и неопознанной GAL-платой тестера не было.
Не проверены все MIDI/трековые форматы, все музыкальные программы, долгие
многочасовые сессии, аналоговое звучание колонок и другой физический компьютер.
GUI-настройки проверены программно; ручная приёмка работы в основном окне
и субъективное прослушивание остаются за пользователем.
