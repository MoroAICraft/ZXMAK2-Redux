# ZXMAK2-Redux 0.98 — 2026-11-04

Regular release of the user-tested and accepted v98 runtime. Publication changes
the project presentation and source distribution; the accepted EXE/DLL bytes are retained.

- Includes ZXM-SoundCard Extreme Rev.03 and standalone ZX OPL3 (UR4QBP), alongside
  NeoGS, TurboSound FM Pro, MultiSound, MultiSound Max, MoonSound and OmniSound.
- Windows Open with for TRD/SCL/TAP/SNA, multi-instance selection, File/Open and drag/drop.
- Retains the accepted v96 recovery changes and v97 ZX OPL3 implementation.
- Host-rate PCM avoids redundant DAC reconstruction; card volume handling and
  DC-history recovery are corrected. MultiSound Max no longer inherits OPL4 FM attenuation.
- Self-contained source checkout, including exact ZX-OmniSound sources.

## Installation

Clean starts without the saved root machine-state files. Full includes the prepared
ZX OPL3 profile with no mounted user media. Extract into a new writable directory;
do not overwrite a running emulator or merge DLLs with an older installation.
Start ZXMAK2.exe manually once before using Windows Open with.

## Limits retained from the accepted build

No new anti-alias resampler, automatic gain control or equalizer is introduced.
The existing resampler and signed-16-bit sum of the two YM2203 streams retain
the limitations documented in the audio audit. MultiSound Max OPL3 is about 9 dB
louder after removal of the unrelated attenuation: start with moderate volume.
MoonSound's OPL4 mixer/register behavior is retained. User acceptance does not
claim measurement of every real hardware arrangement or cycle-perfect sound equivalence.
YRW801-M instrument ROM and user media are not supplied.

## По-русски

Обычный выпуск принятой пользователем v98 под публичным номером **0.98**.
Проверенные EXE/DLL сохранены без изменений. Обновлены оформление, инструкция
и публикация полных исходников, включая ZX-OmniSound.

Поддерживаются Extreme Rev.03, отдельная ZX OPL3 (UR4QBP) и остальные платы из
README. Доступны «Открыть с помощью» для TRD/SCL/TAP/SNA, выбор экземпляра,
открытие из меню и перетаскивание. Сохранены изменения устойчивости v96 и карта v97.
Исправлены повторная обработка готового PCM, обработка громкости/DC-истории
и несоответствующее ослабление OPL3 в MultiSound Max.

Clean не содержит сохранённых корневых файлов состояния машины. Full включает
подготовленный профиль ZX OPL3 без подключённых пользовательских носителей.
Распаковывайте отдельно от рабочей установки. После переноса один раз запустите
EXE вручную для регистрации «Открыть с помощью».

Ограничения прежнего ресэмплера и signed16-суммы двух YM2203 остаются;
новые AGC, эквалайзер или антиалиасинговый ресэмплер не добавлялись.
OPL3 MultiSound Max стал примерно на 9 дБ громче — начните с умеренной громкости.
Приёмка пользователя не означает проверки всех аппаратных сочетаний.
