# ZXMAK2-Redux 0.98

ZX Evolution emulator for Windows with configurable ZXBUS sound hardware.

- Sound cards: NeoGS C-VS, TurboSound FM Pro Rev.C, ZX-MultiSound Rev.A2,
  ZX-MultiSound Max, ZXM-MoonSound Rev.01, ZXM-SoundCard Extreme Rev.03,
  ZX OPL3 (UR4QBP) and ZX OmniSound Virtual.
- Drag and drop, File/Open and Windows **Open with** for TRD/SCL/TAP/SNA.
- Mount disks, SD cards and PC folders from the toolbar. Folders can act as
  virtual SD cards with read/write support and confirmed saving back to the folder.

Download **Clean**, extract the archive and run `ZXMAK2.exe`.
Windows and .NET Framework 4.6.2 or newer are required.
Start the extracted copy manually once before using **Open with**.
MoonSound PCM requires a separately obtained YRW801-M instrument ROM.

[Features, screenshots and instructions](https://github.com/MoroAICraft/ZXMAK2-Redux#readme)

## Русское описание

Эмулятор ZX Evolution для Windows с настраиваемыми звуковыми платами ZXBUS.

- Звуковые карты: NeoGS C-VS, TurboSound FM Pro Rev.C, ZX-MultiSound Rev.A2,
  ZX-MultiSound Max, ZXM-MoonSound Rev.01, ZXM-SoundCard Extreme Rev.03,
  ZX OPL3 (UR4QBP) и ZX OmniSound Virtual.
- Перетаскивание файлов, меню «Открыть» и Windows **«Открыть с помощью»**
  для TRD/SCL/TAP/SNA.
- Диски, SD-карты и папки легко монтируются через панель инструментов.
  Папки работают как виртуальные SD-карты с чтением, записью и сохранением
  изменений обратно в папку после подтверждения.

Скачайте **Clean**, распакуйте архив и запустите `ZXMAK2.exe`.
Нужна Windows и .NET Framework 4.6.2 или новее.
Для «Открыть с помощью» сначала один раз запустите распакованную копию вручную.
Для PCM-звука MoonSound нужен отдельно полученный инструментальный ROM YRW801-M.

[Возможности, скриншоты и инструкции](https://github.com/MoroAICraft/ZXMAK2-Redux#русское-описание)
