Что изменено
------------
1. Ctrl+F переключает существующий No Flick. Состояние отражается в меню.
   Используется общий маршрутизатор клавиш; сочетание не уходит машине.
   F10, PrintScreen/NMI и существующие сочетания не переназначены.

2. Для активной ZX-Evo BSconf File/Open, drop и Open With используют одну
   политику: TRD/SCL/TAP/SNA. Другие машины сохраняют прежние форматы и режим
   read-only при открытии извне. SD/IDE подключаются отдельными командами.
   Перед изменением машины проверяются содержимое и размер файла.
   Повреждённые/неподдерживаемые файлы не вытесняют прежний носитель.
   TAP ограничен 32 млн развёрнутых импульсов для защиты 32-битного процесса
   от исчерпания памяти, в том числе при множестве крошечных блоков.

   TRD/SCL: свободный физический A выбирается автоматически, иначе диалог
   дисковода. Виртуальный привод BaseConf, перекрывающий физический, исключён.
   SCL вставляется отдельной дискетой, не дописывается в старую.
   Несохранённая дискета: Save & Replace / Discard & Replace / Cancel.
   Save создаёт локальную UDI-копию с сохранением дорожек; внешний оригинал
   дискеты не перезаписывается. Это не меняет direct-save выбранной SD-папки.

   TAP: подключается к магнитофонному входу. Пункт T. Tape load в ERS работает
   при L. Emu tape load = OFF. ON — другой, гостевой загрузчик TAP с SD;
   CMOS автоматически не подменяется. Auto Play/Quick Load или ручной Play.
   SNA: поддержаны существующие размеры 49179/131103, после восстановления
   нет дополнительного Reset. Дублированные bank 2/5 варианты не добавлены.

3. Windows Open With: регистрация четырёх расширений только в HKCU, без
   назначения приложением по умолчанию и без прав администратора.
   Запрос передаётся уже запущенной копии из той же папки через защищённый
   текущим пользователем named pipe. Диалог откладывает открытие файла.
   После переноса нужна первая загрузка EXE из нового места. Старые записи
   Windows могут остаться: записи других установок автоматически не удаляем.

4. При Apply смены звуковой карты/аппаратных параметров пересоздаются связи
   шины и выполняется существующий DoPowerCycle внутри того же процесса:
   RAM очищается, машина начинает загрузку заново, CMOS и носители остаются.
   Несохранённая SD-сессия требует решения до полного переподключения.
   Ошибка live-reload восстанавливает прежнюю конфигурацию и перезапускает
   её; это восстановление конфигурации, не точного состояния CPU/RAM.
   Если восстановление невозможно, машина остаётся на паузе с ошибкой.

5. Безопасная оптимизация: Apply только громкости/без изменений не
   переподключает шину и не сбрасывает музыку, таймеры или машину.
   Убрана ошибочная связь reattach Extreme с физическим ResetBoard.
   Неизменённая дискета сохраняется в памяти вместе с несохранёнными правками
   при Apply. Путь SD после Save As переносится в применяемую конфигурацию.
   Чтение позиции пустой ленты больше не обращается к отсутствующему блоку.
