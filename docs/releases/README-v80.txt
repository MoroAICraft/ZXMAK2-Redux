ZXMAK2 v80 / ZX-Evo BaseConf / Optimization Test / 2026-10-07

Основа: контрольная v79 (1993dd0). Только безопасная оптимизация движка.
В BusManager повторные проверки неизменных интерфейсов устройств вынесены
из исполнения каждого такта в штатное подключение/смену профиля.
Частоты, задержки, карта памяти, события и результаты устройств НЕ кешируются.
CPU, видео, SD-сессии, клавиши и звуковые алгоритмы не менялись.
Эксперимент с очередью звука исключён: устойчивого выигрыша не было.

Все runtime-файлы кроме ZXMAK2.Engine.dll и этого README взяты из v79
без изменений. Сохранены Test.exe, ROMS.PAK, native music DLL и SoundFont.
Диагностические программы/исходники/логи не входят в пользовательские ZIP.

ZIP Clean — без личных VMZ/VMIDE/CMOS и отдельного пользовательского ROM.
Полный ZIP — с контрольным профилем v79. Его путь к SD-папке может не существовать
на вашем компьютере: выберите свою папку/образ. Папки D:\release77 и другие
рабочие пользовательские установки не изменены.

Проверены регрессии клавиатуры, семи рендеров, WAIT/INT/NMI, видеотайминга,
ленты, SD сохранения/обновления/экспорта/переноса и звуковых устройств.
Сравнение CPU/RAM/video/PCM/I/O/tact с v79 — отдельный тест, не benchmark.
Результаты времени и ограничения: docs/history/OPTIMIZATION_V80_REPORT.md
в исходниках и diagnostics/ данного пакета. Это измерения двигателя на данном
компьютере, не обещание ускорения всех игр/оконных/GPU backend.

Откат: распаковать сохранённую v79 в отдельную папку. Не переносить её DLL
по одной в работающий эмулятор. Исходники: метка zxmak2-v79-control;
актуальная ветка: codex/optimization-v80, метка zxmak2-v80-optimized.
Индекс версий: docs/LOCAL_VERSIONS.md. Полные source ZIP и local Git bundle
сохранены рядом с тестовым пакетом. На GitHub ничего не публиковалось.

Качество звука — следующий отдельно обсуждаемый этап, не часть v80.
TS-Conf/ATM Turbo 2 в этом этапе не добавлялись и не заявлены проверенными.
