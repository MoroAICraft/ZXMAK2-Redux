ZXMAK2 v95 — Open With, отдельная тестовая сборка, 3 ноября 2026

База: v94 с проверенным пользователем исправлением NMI, все функции v93/v92.
CPU, NMI, звук, платы, загрузчики и рабочие носители не менялись.

Один пункт Windows «Открыть с помощью» — ZXMAK2 (TRD/SCL/TAP/SNA).
Одна открытая копия v95: передаём ей. Несколько: выбираем окно по папке/пути.
Ни одной: открываем последнюю нормально запущенную копию.
Обычный запуск EXE, File/Open и drag/drop остаются локальными для своей копии.

Для проверки нескольких экземпляров распакуйте в две отдельные доступные
для записи папки. Рабочие конфиги и подключённые диски у них независимы.
Старые версии не участвуют в новом выборе окон. Они могут добавлять прежние
регистрации обратно; для общего механизма нужны обновлённые экземпляры.
После переноса папки один раз запустите её ZXMAK2.exe вручную.

При первом обычном запуске регистрация текущего пользователя обновляется.
Проверенные старые записи скрываются, но не удаляются целиком: прежние
выбранные ассоциации продолжают работать. Чужие приложения и UserChoice
не меняются. Перед записью создаётся резервная копия только затрагиваемых
значений: Data/Backups/OpenWith/*.reg. Нет службы или глобального перехвата.

Full сохраняет настройки исходного комплекта; внешние пути могут указывать
на ваши реальные носители. Для безопасной проверки используйте Clean
или подключайте только тестовые копии файлов. Папки SD/BC в комплекте нет.
Регистрация на компьютере — намеренное исключение из переносимости:
другому компьютеру нужен первый ручной запуск для «Открыть с помощью».

Откат runtime: неизменённый полный v94 ZIP в rollback или прежняя установка.
Для отката регистрации закройте все копии и импортируйте нужный .reg из
Data/Backups/OpenWith. Несколько откатов применяют от нового к старому.
Не смешивайте DLL разных версий. Старые архивы/установки не изменялись.
Тестовая v95 не становится основной без подтверждения пользователя.
