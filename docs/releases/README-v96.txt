ZXMAK2 v96 — Fault Recovery TEST, 3 ноября 2026

Отдельная тестовая сборка на принятой v95. Установленные копии и рабочие
носители не изменялись. Не становится основной без подтверждения пользователя.

Исправлено:
1. Внутренний SD IMG: повтор после частичного сохранения больше не отвергает
   собственную запись как внешнее изменение. Журнал остаётся до завершения.
   При незавершённом сохранении — Retry / Cancel вместо опасного Discard.
   Новые записи гостевой машины блокируются до завершения сохранения.
2. SD-папка: read-only файлы не заменяются; сессия остаётся доступной.
   Неудачная уборка служебного резерва не выдаётся за неудачное сохранение.
   Путь оставленного резерва записывается в журнал; защита файлов не снимается.
3. DirectSound: повторное создание вывода после ошибки с интервалом 1 секунда.
   Пока звук недоступен — синхронизация по времени; после восстановления
   возвращается звуковая. Размер штатного буфера, качество и громкость прежние.

Остальная логика прежняя: выбранная SD-папка сохраняется на месте, Refresh
перечитывает её; копия всей папки не создаётся. Внешний отдельный SD IMG,
как и раньше, при сохранении создаёт локальную копию в Data/Saves/SD-Images.
Open With, Print Screen/NMI, клавиши, звуковые карты и переносимость сохранены.

Full содержит конфигурацию прежнего комплекта: её пути могут вести к вашим
рабочим носителям. Для безопасной проверки выбирайте Clean и тестовые копии.
Не смешивайте DLL разных сборок. Распакуйте комплект в отдельную папку.

Быстрая проверка: работа с SD-папкой, Save/Refresh/закрытие, обычный звук
и пауза/продолжение. Не отключайте накопители и не портите реальные файлы:
сбои записи уже проверялись отдельным стендом на маленьких тестовых носителях.
Физический unplug HDMI/USB, сон/гибернация и реальное заполнение диска
не проверялись; гарантии восстановления при любом отказе оборудования нет.

Откат: закройте v96 и используйте прежнюю папку v95 либо распакуйте полный
v95 ZIP из rollback в отдельную папку. После незавершённой записи IMG сначала
завершите Retry; не удаляйте Data/Sessions/SD/Images и не переносите отдельно
повреждённый образ без журнала. Откат программы не откатывает данные носителей.
Исходники с OmniSound и обе Git-истории — в source. GitHub не изменялся.
