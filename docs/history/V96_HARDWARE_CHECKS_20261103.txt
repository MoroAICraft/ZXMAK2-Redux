ZXMAK2 v96 — проверки на компьютере пользователя, 3 ноября 2026
============================================================

Итог
----
Проверены смена основного звукового выхода, отключение/включение двух render
endpoint через Windows, один настоящий S3 сон/пробуждение, блокировка/ручная
разблокировка при этом сне, fullscreen, minimize/restore, перенос между двумя
мониторами и штатное завершение после этих переходов. Зависания VM, зависания
выхода из программы и невосстановившегося видеовывода в этих опытах не было.
Проверка непрерывности аудиопотока пройдена; слышимость/качество записи и
физический unplug кабеля этим НЕ подтверждены. Не все аппаратные риски закрыты.
Рабочей базой остаётся принятая v96. Новая версия не выпускалась.

Ограничения и незакрытые пункты
------------------------------
- Кабели HDMI/USB физически не извлекались. Отключение render endpoint в UI —
  отдельный, более узкий сценарий. Для настоящего unplug нужна помощь человека;
  рабочие диски и USB-накопители извлекать ради теста нельзя.
- Драйвер не вернул DirectSound ошибку при аудиопереходах; реальные отказы,
  ведущие в его retry, здесь не воспроизведены. Предыдущие 85 assertions с fake
  native остаются отдельным программным доказательством, а не аппаратным тестом.
- Не записан контрольный аудиосигнал/loopback; live worker и очередь не доказывают
  слышимость, отсутствие щелчков и правильный физический маршрут на каждом шаге.
- Гибернация, RDP, потеря GPU с driver reset/TDR, смешанные GPU, все мониторы,
  многократные циклы сна и многочасовой музыкальный прогон не проверялись.
- Зависание внутри native драйвера, физическое заполнение диска, отключение
  питания, UNC timeout, dynamic VHD fault campaign остаются ограничениями.
  Рабочий компьютер/диски намеренно не доводились до этих аварий.

Артефакты и безопасность
-----------------------
diagnostics/hardware-session.txt — непрерывная телеметрия двух успешных сеансов.
diagnostics/ZXMAK2.log — штатный лог; diagnostics/power-events.xml — Windows.
diagnostics/*before.csv / *after*.csv — устройства; runtime-comparison.csv — SHA.
source/HardwareSessionProbe.cs + PortableBootstrap.cs — исходник измерителя.
Измеритель сначала ошибся порядком инициализации WinForms (05:14:06):
SetCompatibleTextRenderingDefault после создания окна Timer. Исправлен только
порядок запуска измерителя; это не ошибка принятой v96. Первый неудачный запуск
оставлен в логах, чтобы не скрывать происхождение его EXCEPTION.

Для повторения компиляция csc.exe из .NET Framework v4.0.30319, target winexe,
platform x86; references System.Windows.Forms.dll, System.Drawing.dll и все
Lib/Managed/ZXMAK2*.dll; исходники измерителя и src/PortableBootstrap.cs.
Конфиг измерителя — копия ZXMAK2.exe.config. Запуск только в отдельной Clean
поставке с пустыми слотами; не подменять основной EXE этим измерителем.
Измеритель сам НЕ выключает устройства и НЕ вызывает сон.

Production-исходники, официальные Full/Clean/rollback, установленные копии и
пользовательские носители остались неизменны. На GitHub ничего не публиковалось.
Сохранены только отдельные диагностика/исходники измерителя и актуализирован план.
