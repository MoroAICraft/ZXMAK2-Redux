# v88 — звуковые карты и контроль переносимости

Пользователь разрешил подготовить отдельную тестовую v88 и исправить найденные
явные ошибки переносимых путей. v87 ещё не принята пользователем; v88 также

Пакет: `L:\Work_two\ZX\ZXMAK2-v88-Portable-SoundCards-Test-20261010`.
Полная копия runtime v87 сохранена в `baseline-v87`, прежний пакет/source/tag
v87 не изменяются. Четыре preexisting untracked engine-research файла сохранены.

1. Подтверждённые ошибки из отдельного SoundCards-Audit: feedback 4–7,
   алгоритмы 2/3, DT/KS и неполная модель YM2203. Для перехода трёх карт на
   имеющееся ymfm запрошено отдельное подтверждение. До ответа общие ядра
   автоматически не заменять; можно выполнять независимые переносимые правки.
2. Общие SSG-записи должны уведомлять YM2203 о data-cycle/BUSY без второго
   слышимого SSG. FM write-only регистры не должны читаться из shadow-cache;
   I/O A/B разрешены только в SSG-диапазоне. Аппаратные декодеры сохранить.
3. Max OPL3: преобразование 44,1 кГц → host-rate отдельно от принятой MoonSound.
4. Переносимость: IDE ATM/Profi/Sprinter/SMUC должны закрывать диск и сохранять
   актуальный внутренний путь в VMIDE при отключении; CMOS без назначенного
   sidecar не должна пытаться открывать null. Другие явные ошибки путей
   исправлять только с проверкой, не переписывать структуру заново.
5. Проверки: OPN алгоритмы/feedback/DT/KS/таймеры/чтения/сброс/независимость,
   четыре пользовательских TFC/TFD, нагрузка относительно контроля, Max
   44,1/48/96 кГц, старые TSFM/MultiSound/Omni/Moon тесты, переносимые paths,
   модели и регрессии CPU/видео/клавиатуры/SD/tape. Отдельно указать всё,
   что не проверено на физической карте или в реальном OmniPlayer.
6. Отдельный runtime, Full/Clean ZIP, исходники с pinned OmniSound, обе истории
   Git и отчёт. Исходники/сборки сохранять контрольными точками; до явной
   пользовательской приёмки статус TEST. D:-папки пользователя не заменять.
