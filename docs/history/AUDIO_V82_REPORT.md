## Подтверждённая причина и границы исправления

Старый FrameSound делил сумму на число ВСЕХ рендереров, включая молчащие
части комбинированных плат. Moon-only давал делитель 4, Rev2 — 9. Один
молчащий AY может выдавать постоянный signed -32768, а не ноль. Нельзя
сначала ограничивать/преобразовывать эту сумму в short, потом убирать DC.
Старый финальный DC-фильтр имел фиксированные коэффициенты: при 44,1 кГц
ослабление 20 Гц -11,286 дБ, 50 Гц -4,758 дБ; при других частотах ещё и
изменял частотную характеристику. MoonSound.Volume игнорировался native
выводом: 0/50/100% давали одинаковый сигнал.

Общее исправление: wide double сумма, фиксированная выходная калибровка 0.5
(6 дБ запаса, не деление по количеству плат), DC до сужения разрядности,
один фильтр 5 Гц с коэффициентом exp(-2*pi*5/Fs), затем master и один
мягкий ограничитель с порогом 24576. Тихие участки не поднимаются автоматически;
MIDI CC7/CC11/velocity и аппаратная динамика не переписаны. На перегрузке
мягкий ограничитель намеренно меняет сигнал; ниже порога он линейный.

Старые конструкторы FrameSound сохранены для двоичной/исходной совместимости.
BusManager выбирает новый тракт для всех существующих/будущих профилей,
которые используют его SoundFrame; сторонний обход этого API не охватывается.
Переключатель ULA > Audio Output > Legacy audio mix (v81) сохраняется как
`legacyAudioMix=true` в профиле. Это точный старый mixer/DC путь, но не
восстановление ошибки игнорирования MoonSound.Volume. Полный откат — v81 ZIP.
