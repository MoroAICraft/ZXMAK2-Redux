ZXMAK2 v91 — ZXM-SoundCard Extreme Rev.03, 2026-10-28
TEST build; approval by the user is required before adopting as the working base.

SCOPE AND HARDWARE
Separate ZX Evolution ZXBUS board. Not a renamed MultiSound or OmniSound.
Primary specification: http://micklab.ru/My%20Soundcard/ZXMSoundCard.htm
Local references: L:/Work_two/ZX/_reference_ZXM-SoundCard-Extreme-20261028.
Rev.03 adds mounting holes; digital implementation follows the Rev.02 schematic
and Rev.01 V0100 dd2.tdf. EPM7064/7128 equations agree. No external firmware file
is needed at runtime: the CPLD logic is implemented as bus behavior.

2 x YM2203, SAA1099, TLC7226. No GS, MIDI UART, OPL3/4 or sample-ROM block.
YM address/read mask C0FF=C0FD, data C0FF=80FD. F0..FF values set board config.
Reset config E: YM0, register read, FM DAC off, SAA clock off.
#FFFC mask F0FF=F0FC; bits0/1 select 3.5/2/4 MHz; bit7 forces YM0, preserves YM1.
FM synthesis, SSG oscillators and timers track the selected external clock.
No address/data reset on clock switching. FM DAC mute does not stop timers/core.
PA/PB are unconnected; input reads FF. FM registers do not fabricate readback.

JP1 gates YM chip access only; board config/clock writes remain available.
JP2 closed (default) uses the end-of-every-memory-read latch, NOT only M1.
A14|A15 controls SAA/DAC visibility; writes do not change that latch.
JP2 open uses physical ZXBUS /DOS (mapped page bit), not Memory.DOSEN.
IODOS is pulled high on BaseConf. YM/config ports are independent of this gate.
JP3 closed: #05FF address / #04FF data, mask CEFF=04FF. Legacy option opens JP3:
#01FF/#00FF, mask C0FF=00FF. Bit3 config stops the clock, not register writes.
There is no fictitious AY-port redirection to SAA. SAA/DAC have no reset pins;
CPU reset preserves their registers. Power-on uses deterministic initial state.
DAC decode 00AF=000F plus #3F and #FB, A4/A6 selects channel. #B3 deliberately
excluded in author's CPLD. A+B left, C+D right. PSGs both A-left/B-centre/C-right;
B relative resistor weight 24/47, approximated by 51%. FM on both outputs.

UI AND CONFLICT PROTECTION
Alt+P -> Other / ZXBUS PentEvo -> Slot 1 or 2 -> ZXM Extreme Rev.03.
Hardware jumpers and board volume are saved in VMZ. Internal AY/YM disabled
while Extreme owns YM; JP1 may release it. MultiSound/Max/Omni rejected because
ports overlap. Internal TSFM with optional MultiSound-SAA aliases is rejected
when JP1 releases YM. MoonSound/NeoGS/ZXNetUSB may use the other slot.
Standalone CovoxMono does not double-mix an Extreme-owned #FB write.
Existing enum entries keep their numeric values (new entry appended).
Full package selects Extreme in slot1 and mounts no media. Clean archive omits
root sidecars, retaining existing factory template; choose Extreme manually.

LIMITS / NOT VERIFIED
No physical Extreme board A/B capture; analogue levels/filtering and power-on
undefined values are not measurement-calibrated. Not a claim of bit-perfect DAC.
Shared OPN timers/BUSY retain existing host-audio-sample scheduling granularity
(about 22.7 us at 44.1 kHz); sub-sample/cycle-perfect edges are not established.
No manual full TRD launch, NedoOS/OmniPlayer listening session, physical 2-card
combination, full 4K UI interaction or test on another physical Windows PC.
Guest music test calls the real author's routine, NOT the entire TR-DOS loader.
Automated UI checks initialize/apply controls; offscreen preview is not a complete
human visual/DPI check. Machine tests do not establish compatibility of every game.
No v83 HQ path, no overall sound redesign, no external-media changes.
